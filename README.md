# Um date comigo? 💙

Convite interativo em português, adaptado para celular e computador.

- Abertura com carinha chorosa e corações flutuantes.
- Cada toque em **Não** muda a frase e a posição de uma caixinha suplicante.
- **Sim** troca para a carinha mordendo uma rosa.
- Escolhas de data, horário, comida e passeio.
- Resumo final para copiar e compartilhar.

## Executar

Abra `index.html` no navegador ou acesse a publicação do GitHub Pages.
As imagens, os estilos e o JavaScript estão incorporados no arquivo.
Não é necessário instalar dependências nem compilar.

## Personalizar

Edite o objeto `CONFIG` dentro de `index.html`. Nele estão os textos,
as frases do botão Não e as opções de comida e passeio.

## Publicar no GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**,
a branch **main** e a pasta **/(root)**, e salve.
O arquivo `.nojekyll` permite publicar o HTML diretamente.

## Respostas

As escolhas ficam somente na sessão do navegador. Não há banco de dados,
coleta de informações ou envio automático de mensagens.
Use **Copiar nosso combinado** para enviar o resumo por sua conta.
